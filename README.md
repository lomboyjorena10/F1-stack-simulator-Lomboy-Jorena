### Activity Overvie
This repository contains the starter files for the Week 11B: Pre-Lesson Reading Activity (Stack Simulator Web App) for CC104 - Data Structures. 

The purpose of this activity is to explore the basic user interface of a web-based Stack Simulator before creating dynamic interactions. It integrates fundamental web development tools to simulate a dynamic data structure environment.

---

### Tech Stack & Tools Explained
Based on the pre-lesson reading materials, here is the core role of each technology used in this project:
- HTML: Defines the fundamental page structure, including the input fields, operation buttons, and layout containers.
- CSS: Handles the custom visual presentation, such as container sizes (e.g., 50px blocks) and background styling.
- Bootstrap: Supplies pre-made components and utility classes (like `btn-success` and grids) for clean layout arrangement.
- JavaScript: Manages the logic, tracking core operational behaviors and structural data via the `Stack` class.
- jQuery: Acts as a shorthand library to easily manipulate the DOM, selecting containers and prepending new blocks dynamically.
